    - Call client.SetLocation(hash, newLocation)
    - Return raw error

    - Get torrent files via client.GetTorrentFiles(hash)
    - Filter video files (.mkv, .mp4, .avi, .flv, .ts, .m2ts, .wmv, .mov)
    - Extract episode numbers from filenames using extractEpisodeFromFilename pattern
    - Sort by episode number
    - For each video file:

    - Return count of renamed files

      - Rename if filename different (RenameViaQBittorrent)
