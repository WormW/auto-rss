2. Add token extraction and validation logic at the start of the handler:
   - Extract `token` query parameter: `c.Query("token")`
   - If token is empty, return 401: `c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{"code": 401, "message": "Token required"})`
   - Call `jwtService.ValidateAccessToken(token)` to validate
   - If validation fails, return 401 with message "Invalid or expired token"
   - If validation succeeds, proceed with connection upgrade

3. Update `NotificationHandler` to store JWT service reference:
   - Add `jwtService auth.JWTService` field to `NotificationHandler` struct
   - Update `NewNotificationHandler` to accept and store JWT service
   - Update `WebSocketHandler` to pass JWT service to `HandleWebSocket`

4. Ensure the clientID includes user identification:
   - Use `claims.UserID` as part of clientID instead of just IP + timestamp
   - Format: `fmt.Sprintf("user_%d_%s_%s", claims.UserID, c.ClientIP(), time.Now().Format("20060102150405"))`
