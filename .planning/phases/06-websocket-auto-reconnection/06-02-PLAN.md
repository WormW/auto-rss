Create web/src/services/websocket.ts with the following implementation:

1. Configuration constants (per D-07, D-08, D-09):
   - BASE_DELAY = 1000 (1 second)
   - MAX_DELAY = 30000 (30 seconds)
   - MAX_RETRIES = 10
   - JITTER_FACTOR = 0.5 (±50%)

2. WebSocketService class with these properties:
   - private ws: WebSocket | null
   - private url: string
   - private reconnectAttempt: number = 0
   - private reconnectTimer: number | null
   - private messageBuffer: Array<{payload: NotificationPayload, timestamp: number}>
   - private store: WebSocketStore (passed in constructor)
   - private isManualClose: boolean = false

3. Core methods:
   - connect(token: string): void - Initialize connection with JWT token in URL
   - disconnect(): void - Clean close with isManualClose = true
   - reconnect(): void - Force immediate reconnection attempt
   - send(payload: NotificationPayload): void - Send or buffer message
   - getStatus(): ConnectionStatus - Return current connection state

4. Reconnection logic (per D-07, D-08):
   - calculateDelay(): number {
       const exponential = BASE_DELAY * Math.pow(2, this.reconnectAttempt)
       const capped = Math.min(exponential, MAX_DELAY)
       const jitter = capped * JITTER_FACTOR * (Math.random() * 2 - 1)
       return Math.max(0, capped + jitter)
     }

5. Event handlers:
   - onOpen: Set status to 'connected', reset reconnectAttempt, flush buffer
   - onClose: If !isManualClose and code !== 1000, schedule reconnection
   - onError: Log error, status becomes 'error'
   - onMessage: Parse JSON and call store.onMessageReceived()

6. Buffer management (per D-14, D-15, D-16, D-17):
   - Buffer messages when status !== 'connected'
   - Max buffer size: 100 (drop oldest when exceeded)
   - TTL: 5 minutes (300000ms) - discard expired on flush
   - Flush buffer in order after onOpen

7. Page visibility handling (per D-13):
   - Add document visibilitychange listener in constructor
   - If document.visibilityState === 'visible' and status === 'disconnected', call reconnect()

8. Connection status type:
   - 'connecting' | 'connected' | 'disconnected' | 'error' | 'max_retries_exceeded'

Per D-07, D-08, D-09, D-11, D-12, D-13, D-14, D-15, D-16, D-17.
