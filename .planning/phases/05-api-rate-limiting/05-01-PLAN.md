## Key Implementation Details from CONTEXT.md

### Token Bucket Parameters (D-04, D-11)
- General API: 10 req/s (RATE_LIMIT_RPS), burst 20 (RATE_LIMIT_BURST)
- Auth endpoints: 5 req/min (RATE_LIMIT_AUTH_RPM), burst 5
- Use `golang.org/x/time/rate` as recommended library

### Storage Constraints (D-05, D-06)
- TTL: 1 hour for inactive clients
- Max entries: 10,000
- Eviction: LRU when max entries reached

   ```go

       key    string
   ```

5. Type Store struct:
   ```go
   type Store struct {
       buckets   map[string]*entry
       lru       *list.List // Front = most recent
       mu        sync.RWMutex
       maxEntries int
       ttl       time.Duration
       defaultRPS float64
       defaultBurst int
   }
   ```

6. Constructor `NewStore(maxEntries int, ttl time.Duration, rps float64, burst int) *Store`:
   - Initialize map, LRU list
   - Set parameters (use defaults if zero values)
   - Return store instance

7. Method `GetBucket(key string) *Bucket`:
   - Acquire write lock
   - Check if entry exists:
     - If yes: move to front of LRU list, update lastAccess, return bucket
     - If no: check if at capacity (len >= maxEntries)
       - If at capacity: remove oldest (lru.Back()), delete from map
       - Create new bucket with defaultRPS/defaultBurst
       - Add to map and front of LRU list
       - Return new bucket

8. Method `GetBucketWithRate(key string, rps float64, burst int) *Bucket`:
   - Same as GetBucket but uses provided rate instead of defaults
   - Used for auth endpoints with different limits

9. Method `Cleanup() int`:
   - Acquire write lock
   - Iterate through all entries
   - Remove expired entries (IsExpired(ttl))
   - Return count of removed entries

10. Method `Len() int`:
    - Acquire read lock
    - Return len(buckets)

11. Method `Stats() (total int, oldest time.Time)`:
    - Acquire read lock
    - Return total entries and oldest entry's last access time
