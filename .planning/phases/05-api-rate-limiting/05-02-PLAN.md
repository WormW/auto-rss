## Key Implementation Details from CONTEXT.md

### Middleware Mounting (from code_context)
- Mount order: Logger -> Recovery -> CORS -> RateLimit -> Auth
- Rate limit should be before Auth to prevent auth computation exhaustion

### Rate Limit Scope (D-01, D-02, D-03)
- All API endpoints except `/health` get rate limited
- Auth endpoints (`/api/v1/auth/login`, `/api/v1/auth/refresh`): 5 req/min, burst 5
- General endpoints: 10 req/s, burst 20
- IP-based limiting (c.ClientIP())

### Headers (D-07, D-08, D-09)
- X-RateLimit-Limit: Maximum requests allowed
- X-RateLimit-Remaining: Remaining requests in current window
- X-RateLimit-Reset: Unix timestamp when limit resets
- Retry-After: Seconds to wait (on 429 only)

### Error Response Format
```json
{
  "code": 429,
  "message": "请求过于频繁，请稍后再试"
}
```

4. Function `RateLimitWithConfig(config RateLimitConfig) gin.HandlerFunc`:
   ```go
   return func(c *gin.Context) {
       path := c.Request.URL.Path
       clientIP := c.ClientIP()
       
       // Check excluded paths
       for _, excluded := range config.ExcludedPaths {
           if path == excluded {
               c.Next()
               return
           }
       }
       
       // Determine rate limit based on path
       var bucket *ratelimit.Bucket
       var limit, remaining int
       var resetTime time.Time
       
       isAuthPath := false
       for _, authPath := range config.AuthPaths {
           if path == authPath {
               isAuthPath = true
               break
           }
       }
       
       if isAuthPath {
           // Auth endpoint: 5 req/min = 0.083 req/s
           rps := float64(config.AuthRPM) / 60.0
           bucket = config.Store.GetBucketWithRate(clientIP+":"+path, rps, config.AuthBurst)
           limit = config.AuthBurst
       } else {
           // General endpoint
           bucket = config.Store.GetBucket(clientIP)
           limit = config.GeneralBurst
       }
       
       // Check if request allowed
       allowed := bucket.Allow()
       remaining = int(bucket.Tokens())
       resetTime = bucket.ResetTime()
       
       // Set rate limit headers on ALL responses (D-07)
       c.Header("X-RateLimit-Limit", strconv.Itoa(limit))
       c.Header("X-RateLimit-Remaining", strconv.Itoa(remaining))
       c.Header("X-RateLimit-Reset", strconv.FormatInt(resetTime.Unix(), 10))
       
       if !allowed {
           // Calculate Retry-After
           retryAfter := int(time.Until(resetTime).Seconds())
           if retryAfter < 1 {
               retryAfter = 1
           }
           
           c.Header("Retry-After", strconv.Itoa(retryAfter))
           
           logger.Warn("Rate limit exceeded",
               "client_ip", clientIP,
               "path", path,
               "limit", limit,
           )
           
           c.JSON(http.StatusTooManyRequests, gin.H{
               "code":    429,
               "message": "请求过于频繁，请稍后再试",
           })
           c.Abort()
           return
       }
       
       c.Next()
   }
   ```
