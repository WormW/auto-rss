# Plan 07-01: 标签系统 Handler 和路由

## Goal
创建标签系统的 Handler 和路由，实现标签的 CRUD 和订阅标签关联管理。

## Files

### Create
- `internal/api/handler/tag.go`

### Modify
- `internal/api/router/router.go`

## Implementation Details

### TagHandler 结构
```go
type TagHandler struct {
    repo repository.SubscriptionRepository
}
```

### 需要实现的方法

1. **List** - GET /api/v1/tags
   - 返回所有标签列表
   - 按 sort_order 排序

2. **Create** - POST /api/v1/tags
   - 请求体: name, color(可选), description(可选)
   - 验证 name 不为空
   - 默认颜色 #18a058

3. **Update** - PUT /api/v1/tags/:id
   - 支持更新 name, color, description, sort_order
   - 检查标签是否存在

4. **Delete** - DELETE /api/v1/tags/:id
   - 删除标签及关联关系
   - 使用事务

5. **GetSubscriptionTags** - GET /api/v1/subscriptions/:id/tags
   - 获取指定订阅的标签列表

6. **AddTagsToSubscription** - POST /api/v1/subscriptions/:id/tags
   - 请求体: tag_ids []uint
   - 批量添加标签关联

7. **RemoveTagsFromSubscription** - DELETE /api/v1/subscriptions/:id/tags/:tag_id
   - 移除单个标签关联

### 路由注册
在 router.go 中添加:
- 标签路由组: `/api/v1/tags`
- 订阅标签路由: `/api/v1/subscriptions/:id/tags`

## Error Handling
- 400 - 参数错误
- 404 - 标签/订阅不存在
- 409 - 标签名称重复
- 500 - 服务器错误
