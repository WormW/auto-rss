## Implementation Details

### DownloadHistoryHandler 结构
```go
type DownloadHistoryHandler struct {
    downloadRepo repository.DownloadRepository
}
```

### 需要实现的方法

1. **GetHistory** - GET /api/v1/downloads/history
   - 查询参数:
     - subscription_id (可选)
     - status (可选)
     - start_date (可选, YYYY-MM-DD)
     - end_date (可选, YYYY-MM-DD)
     - page (默认 1)
     - page_size (默认 20, max 100)
   - 返回下载历史列表和总数

2. **GetStatistics** - GET /api/v1/downloads/statistics
   - 查询参数: days (默认 7, 统计最近N天)
   - 返回:
     - 各状态数量 (total, completed, failed, downloading, pending)
     - 每日统计 (date, count, completed, failed)
     - 订阅排行 Top 10

## Error Handling
- 400 - 参数错误（如日期格式错误）
- 500 - 服务器错误
