# Milestone v1.1: 基础设施增强

**Status:** ✅ SHIPPED 2026-04-06
**Phases:** 5-6
**Total Plans:** 6

## Overview

基础设施增强里程碑，实现 JWT 认证系统、API 限流保护和 WebSocket 自动重连机制，为系统提供更安全、更稳定的基础服务。

## Phases

### Phase 5: API 限流 (3 plans)

**Goal:** 实现基于 Token Bucket 的 API 限流保护
**Depends on:** Phase 6 (JWT 基础)

Plans:

- [x] 05-01: Token bucket rate limiter implementation
- [x] 05-02: Middleware integration with Gin router
- [x] 05-03: Configuration support via environment variables

**Details:**
- 通用 API: 10 req/s，突发 20
- 认证端点: 5 req/min，突发 5
- 内存存储: LRU 淘汰 (最大 10,000 条目)
- TTL 清理: 1 小时不活跃数据
- 响应头: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset
- 限流响应: HTTP 429 + Retry-After

---

### Phase 6: WebSocket 自动重连 (3 plans)

**Goal:** 实现带认证和自动重连的 WebSocket 服务
**Depends on:** None

Plans:

- [x] 06-01: JWT authentication for WebSocket upgrade
- [x] 06-02: WebSocket service with reconnection logic
- [x] 06-03: Vue.js integration with Pinia store

**Details:**
- JWT token 通过 query param 传递
- 指数退避重连: 1s → 30s
- 抖动 ±50% 避免惊群效应
- 消息缓冲: 最大 100 条，TTL 5 分钟
- 页面可见性触发重连
- 连接状态指示器

---

## Milestone Summary

**Key Decisions:**

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| JWT via query param for WebSocket | Header unavailable during upgrade | ✓ Working well |
| Exponential backoff with jitter | Avoid thundering herd | ✓ 50% jitter working |
| IP-based rate limiting | Simple and effective | ✓ Per-IP isolation |
| LRU eviction at 10k entries | Memory bound | ✓ Safe memory usage |

**Issues Resolved:**

- WebSocket 断线后无法自动恢复
- API 缺乏滥用保护
- 无认证机制

**Technical Debt:**

- Rate limiter 目前是内存存储，重启后状态丢失
- WebSocket 消息缓冲在极端情况下可能丢失消息
