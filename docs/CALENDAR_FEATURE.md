# 追番日历与更新提醒功能文档

## 功能概述

提供追番日历视图展示本周更新的番剧，并在番剧即将更新时发送提醒通知。

## 核心特性

### 1. 追番日历视图

以周为单位展示番剧更新时间：

```
周一
  23:00  芙莉莲 第13集
  24:30  药屋少女 第12集

周二
  22:00  香格里拉 第11集

...
```

### 2. 更新提醒

三种通知时机：

| 时机 | 说明 | 示例 |
|-----|------|------|
| 即将播出 | 提前 N 分钟提醒 | "芙莉莲第13集将在 15 分钟后播出" |
| 新集发布 | RSS 检测到新集时 | "芙莉莲第13集已发布，开始下载" |
| 下载完成 | 下载并整理完成时 | "芙莉莲第13集已下载完成" |

### 3. 播出时间配置

支持配置：
- **更新星期**：周一到周日
- **更新时间**：如 "23:00"
- **时区**：默认 JST（日本时间），自动转换到本地时间
- **提前提醒**：默认提前 10 分钟

## 配置方式

### 订阅级别配置

```json
{
  "name": "葬送的芙莉莲",
  "air_day": "5",          // 周五
  "air_time": "23:00",     // 23:00 播出
  "air_timezone": "JST",   // 日本时间
  "notify_enabled": true,  // 开启提醒
  "notify_before_min": 15  // 提前15分钟提醒
}
```

### AirDay 格式支持

| 格式 | 示例 | 说明 |
|-----|------|------|
| 数字 | "0" - "6" | 0=周日，1=周一... |
| 中文 | "周一", "周二" | 中文星期 |
| 英文缩写 | "mon", "tue" | 英文缩写 |
| 英文全称 | "monday", "tuesday" | 英文全称 |

## API 接口

```bash
# 获取本周排期
GET /api/v1/calendar

# 获取今日排期
GET /api/v1/calendar/today

# 获取指定周排期
GET /api/v1/calendar?week=next

# 更新订阅的播出时间
PUT /api/v1/subscriptions/:id
{
  "air_day": "5",
  "air_time": "23:00",
  "notify_enabled": true,
  "notify_before_min": 10
}
```

## 工作流程

```
定时检查（每分钟）
    ↓
获取今天播出的番剧
    ↓
计算距离播出的时间
    ↓
时间差 <= 提前提醒分钟数？
    ↓
发送"即将播出"通知
    ↓
RSS 检测到新集
    ↓
发送"新集发布"通知
    ↓
下载完成
    ↓
发送"下载完成"通知
```

## 通知事件

| 事件 | 触发时机 | 通知内容 |
|-----|---------|---------|
| `calendar.airing_soon` | 即将播出 | 提醒用户番剧即将更新 |
| `calendar.new_episode` | 新集发布 | 告知新集已开始下载 |
| `download.complete` | 下载完成 | 告知已下载完成可观看 |

## 数据库变更

### subscriptions 表新增字段

```sql
air_day           VARCHAR(10)    -- 更新星期: 0-6
air_time          VARCHAR(10)    -- 更新时间: "23:00"
air_timezone      VARCHAR(10)    -- 时区: JST/UTC/CST
notify_enabled    BOOLEAN        -- 是否开启提醒
notify_before_min INTEGER        -- 提前提醒分钟数
```

## 时区处理

系统默认使用 JST（日本时间 UTC+9）作为番剧播出时间：
- 用户配置 JST 时间
- 系统自动转换为本地时间进行提醒
- 例如：JST 23:00 = CST（中国）22:00

## 向后兼容

- 未设置播出时间的订阅不会显示在日历中
- 提醒默认开启，可随时关闭
- 不影响现有功能

## 注意事项

1. **时区转换**：目前采用固定偏移量，未考虑夏令时
2. **播出时间变化**：部分番剧会因赛事等原因停播，需关注实际播出时间
3. **延迟提醒**：如果系统暂时不可用，可能会错过提醒时间
